# LiteBox UI 2.0 · 01 设计系统

> 方向:**Modern SaaS Dashboard + Infrastructure Console**。视觉上学 shadcn 的克制(细边框、轻阴影、
> 中性灰阶),数据上学 Beszel 的直观(资源条、状态点、时间轴图表),交互上学 Art Design Pro 的流畅
> (抽屉、筛选、浮层的细节)。只借鉴设计语言,不引入它们的技术栈。
>
> 本文替代 V18 的 iOS 视觉细节;V18 建立的**业务交互规则**(状态三重编码、读不到不显示 0、
> 运行与配置分两个标签、进度弹窗关不掉、危险操作四档……)一条都不变。

---

## 1. 令牌在哪里、怎么用

| 位置 | 内容 | 消费者 |
|---|---|---|
| `web/src/styles/tokens.css` | **唯一的设计令牌源**:颜色(浅 / 深)、字号、圆角、间距、阴影、动效、布局尺寸 | 全部 scoped CSS、`base.css`、`antd-tune.css` |
| `web/src/theme/tokens.ts` | 颜色**实值**镜像(`palette.light / dark`)+ `color.*`(`var()` 引用)+ 尺寸常量 | `theme/antd.ts`(ConfigProvider 要实值推导派生色)、少数要在 TS 里拿颜色的组件 |
| `web/src/theme/antd.ts` | `antdTheme(mode)`:令牌 → AntD Token | `App.vue` |
| `web/src/styles/antd-tune.css` | 只放 Token 系统够不到的 AntD 覆盖,每条写明原因 | 全局 |
| `web/src/styles/base.css` | 页面骨架类与工具类(`.lb-page`、`.lb-card`、`.lb-metrics`…) | 全局 |

规则:

1. scoped CSS 里**不写十六进制色、不写 px 字号、不写 px 圆角**,一律 `var(--…)`。
   布局尺寸(列宽、图表高度这类只属于某一页的数)可以写 px。
2. 新增颜色 / 尺寸先加进 `tokens.css`(颜色同时加进 `tokens.ts` 的 `palette`),再使用。
3. 不另起平行的主题系统。深浅色只有一个开关:`<html data-theme>`。

## 3. 字号与字重

8 级字号,散落的 px 值按下表收敛(脚本做确定性映射,见 `02-page-plan.md`):

| 令牌 | 值 | 收敛的旧值 | 用途 |
|---|---|---|---|
| `--fs-2xs` | 11px | 10 / 10.5 / 11 | 角标、计数徽标、图表刻度 |
| `--fs-xs` | 12px | 11.5 / 12 | 元数据、表头、标签、帮助文字 |
| `--fs-sm` | 13px | 12.5 / 13 | 次级正文、紧凑列表 |
| `--fs-base` | 14px | 13.5 / 14 | **默认正文**、表格单元格、按钮、输入框 |
| `--fs-md` | 15px | 15 | 强调正文、卡片内小标题 |
| `--fs-lg` | 16px | 16 / 17 | 模块(卡片)标题、弹窗标题 |
| `--fs-xl` | 18px | 18 / 19 / 20 | 分组标题、抽屉标题 |
| `--fs-2xl` | 24px | 22 / 26 / 28(标题) | 页面标题(手机 20px) |
| `--fs-metric` | 28px | 30 / 32 / 34 / 36 / 44(数值) | 重要指标数字(手机 24px) |

字重:500(按钮、标签、表头)/ 600(标题、强调数值)/ 700(只给 Logo)。
数字一律 `font-variant-numeric: tabular-nums`(`.lb-tabular`),地址、端口、哈希用 `--mono`。

## 4. 间距、圆角、尺寸

**4 / 8 网格**:`--sp-1` 4 · `--sp-2` 8 · `--sp-3` 12 · `--sp-4` 16 · `--sp-5` 20 · `--sp-6` 24 · `--sp-8` 32 · `--sp-12` 48。

| 场景 | 值 |
|---|---|
| 页面内边距 / 页面区块间距 | 24px(手机 16px) |
| 卡片间距 | 16px |
| 卡片内边距 | 20px(手机 16px) |
| 表格单元格 | 12px 16px |

| 圆角令牌 | 值 | 用途 |
|---|---|---|
| `--r-xs` | 4px | 进度条内块、小色块 |
| `--r-sm` | 6px | chip、下拉项、分页按钮、Tooltip |
| `--r-btn` | 8px | **按钮**(不再是胶囊) |
| `--r-input` | 8px | 输入框、选择器、搜索框 |
| `--r-tile` | 8px | 图标底块 |
| `--r-group` | 10px | 卡内分组、Alert、下拉面板、吐司 |
| `--r-card` | 12px | 卡片 |
| `--r-sheet` | 14px | 弹窗 |
| `--r-pill` | 999px | **只给**状态标签、计数徽标、开关 |

## 6. 动效

| 令牌 | 值 | 用途 |
|---|---|---|
| `--dur-fast` | 120ms | hover、颜色过渡 |
| `--dur` | 180ms | 下拉、Tooltip、吐司 |
| `--dur-slow` | 240ms | 弹窗、抽屉 |
| `--ease` | `cubic-bezier(.2,.8,.2,1)` | 通用 |

* 页面进入只做 180ms 的淡入 + 4px 位移,不做弹跳;吐司去掉 V18 的弹跳横幅。
* 图表首次绘制可以有一次轻量过渡,数据刷新不重放动画(避免闪烁)。
* `prefers-reduced-motion` 下全部归零(`base.css` 统一处理)。
* 节点操作仍走 `NodeOpProgressModal` 的步骤表,不用吐司替代。

## 7. 组件规格

### 7.1 导航壳(`MainLayout`)

* **侧栏** 240px,`--surface` 底 + 右侧 1px `--sep`。顶部 56px 品牌区(28px 品牌色方块 Logo + 名称)。
  菜单按「总览 / 资源 / 运维」分组,组名 12px `--text3`。菜单项 36px、圆角 8、图标 18px;
  hover `--fill`;**选中 = `--brand-bg` 底 + `--brand` 文字与图标 + 600 字重**(不再是实底蓝)。
  计数徽标胶囊 `--fill` 底;失败部署计数 `--bad-bg`。底部保留流量同步状态。
* **折叠**:顶栏左侧的切换按钮手动折叠 / 展开,偏好存 localStorage;没设过偏好时按宽度自动
  (≥1280 展开、768–1279 折叠)。折叠后 64px 只剩图标,悬停出 Tooltip 写菜单名。
* **顶栏** 56px,`--surface` 底 + 下边 1px `--sep`,吸顶。左:折叠按钮 + 面包屑(分组 / 页面);
  右:主题菜单(浅色 / 深色 / 跟随系统)、用户菜单(头像 + 用户名 → 退出登录)。
* **手机**(<768):侧栏收进左侧抽屉,顶栏左边是菜单按钮;菜单项 44px。

### 7.2 页面头(`.lb-page__head`)

标题 24px / 600(手机 20px),下面一行 14px `--text2` 的说明;右侧操作区。
页面区块间距 24px。帮助文字仍收在 ⓘ(`LbInfoTip`)里。

### 7.3 卡片(`.lb-card`)

`--surface` 底、1px `--sep` 边框、圆角 12、`--shadow`、内边距 20。卡头用 `.lb-card__head`
(标题 16px / 600 + 可选说明 + 右侧操作)。表格卡 `.lb-card--flush` 无内边距。可点卡片加 `.lb-card--hover`。

### 7.4 指标卡(`LbMetricCard` + `.lb-metrics`)

`.lb-metrics` 从「一张卡里的分隔栅格」改成**独立卡片的网格**(`minmax(220px, 1fr)`,间距 16)。
每张:标签 13px `--text2` + 右上角可选图标;数值 28px / 600;单位 14px `--text3`;底部一行说明 / 标签。
四态不变:error 显示「—」+「加载失败」,**绝不回退成 0**。`tone` 只给数值上色。

### 7.5 表格

表头 `--surface2` 底、12px / 500 `--text3`;单元格 14px、内边距 12px 16px、行分隔 `--sep2`;
行 hover `--surface2`;选中行 `--brand-bg`。分页为 6px 圆角的小按钮,当前页 `--brand-bg` + `--brand`。
行内只留「主操作 + ···」。窄屏 <768 整表换 `LbRowCard`(V3 规则不变)。

### 7.6 按钮

| 类型 | 规格 |
|---|---|
| 主按钮 | `--brand` 实底、白字、圆角 8、36px、`--shadow-xs` |
| 默认 | `--surface` 底 + 1px `--sep`,hover `--fill` |
| 次要(`.lb-btn-ghost`) | `--fill` 底、`--text` 文字、无边框 |
| 文字 / 链接 | 无底,hover `--fill` |
| 危险 | `--bad` 文字或实底 |

按下只做 `scale(.98)`。图标按钮 `.lb-btn-circle` 改成 32px 圆角 8 的方形图标按钮。

### 7.7 标签

* **状态标签** `LbStatusTag`:胶囊、语义浅底、形状图标 + 文字,12px / 500。
* **中性 chip** `.lb-chip`:圆角 6 的矩形(与状态胶囊在形状上区分开:chip 是元数据、胶囊是状态),
  `--fill` 底、12px / 500。

### 7.8 Tabs 与分段控件

* **页面级 Tabs**(`a-tabs`,节点详情、用户详情):下划线式。底部 1px `--sep`,选中项文字 `--text`
  + 2px `--brand` 下划线,未选中 `--text3`。
* **卡内切换**(`.lb-seg`、`a-segmented`、`a-radio-group` 按钮式):分段控件,轨道 `--fill`、
  圆角 8,选中块 `--surface` + `--shadow-xs`。

### 7.9 表单

输入框 36px、圆角 8、1px `--sep`;hover 边框加深;focus 边框 `--brand` + 3px `--brand-bg` 光环。
标签 14px / 500,帮助文字 12px `--text3`,错误 12px `--bad`。

### 7.10 弹窗与抽屉

* **弹窗**:圆角 14、`--shadow-lg`、标题**左对齐** 16px / 600、右上角 32px 关闭按钮;正文内边距 20 24;
  底栏右对齐「取消(默认按钮)+ 确定(主按钮)」,`--surface2` 底 + 上边 1px `--sep2`。
  **去掉 V18 的 `:has()` 三栏头**:所有弹窗一种形态。入场 180ms 淡入 + 0.98 缩放。
* **确认框**(`lbDangerConfirm`):同一套规格,影响范围列表照旧逐条列出。
* **抽屉**:贴右边全高、左侧 1px `--sep` + `--shadow-lg`,头部 `--surface` 底、标题 18px / 600、
  关闭按钮在右上;正文 `--bg` 底(里面的卡片才浮得出来)。手机全屏。
* 遮罩:`rgba(15,23,42,.45)`,不再加模糊。V3 / V18 的兜底规则(渲染错误收住、只读检查跑时遮罩与 ESC 失效、
  进度弹窗跑的时候关不掉)不变。

### 7.11 反馈

* **吐司**:顶部居中的小卡片,`--surface` 底、1px `--sep`、圆角 10、`--shadow-lg`,左侧 16px 语义色图标;
  180ms 淡入下移,不弹跳。
* **Alert**:语义浅底 + 1px 语义描边、圆角 10。
* **Tooltip**:反色(浅色主题下深底白字,深色主题下浅底深字),圆角 6、12px。长说明仍用 `LbInfoTip`
  (浮层规格,`--surface` 底)。
* **空 / 错误态**(`LbEmptyState`):40px 图标底块 + 14px 标题 + 13px 说明;错误态有重试。

### 7.12 图表

* 主序列 `--brand`,面积渐变 `--brand` 16% → 0;多序列用 `--brand` / `--ok` / `--warn` / `--purple`。
* 网格线 `--sep2`,刻度 11px `--text3`;悬停十字线 + 卡片式读数。
* 缺失样本 `null`:折线断开 / 虚线跨过,**不补 0、不插值**(V3 / V20 规则不变)。
* 资源类(CPU / 内存 / 磁盘)在列表里用 Beszel 式的细进度条 + 百分比,颜色按 `threshold.usageWarn / usageDanger`。

### 7.13 门户

与后台共用同一套令牌与 lb 组件,**壳独立**:顶部 56px 导航栏(Logo + 横向导航 + 用户菜单)、
内容最大宽 960、无侧栏、无表格排序与批量、无技术字段(V3 门户规则不变)。
