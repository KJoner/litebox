## 2. 数据库迁移

两个迁移,都只追加,不改任何已应用的迁移;存量数据全部按「未设置」读出。

**0039_asset_billing.sql**

* `expiry_profiles` 加 11 列:`plan_name`、`billing_cycle`、`cycle_count`、`cycle_unit`、`currency`、
  `price_minor`、`purchased_at`、`period_start`、`period_paid_minor`、`period_carry_minor`、`traffic_unlimited`。
  金额是最小货币单位的整数,`-1` = 未填,`0` = 免费;
* `expiry_renewals` 加 3 列:`amount_minor`(`-1` = 没记)、`currency`、`period_start`;
* 新表 `asset_labels(kind, object_id, region, tags)`。**不放进 `expiry_profiles`**:外部代理有了自己的档案行
  就不再跟随来源的到期,只打标签不该带出这个副作用。

**0040_probe.sql**

* `probe_targets`:目标(节点、用途 MGMT / SERVICE、引用、地址族、来源、启停、上一轮解析出的地址与端口、
  口径代号 `generation`、引用状态、告警状态机);
* `probe_results`:每次尝试的原始结果,索引 `(target_id, at)` 与 `(at)`;
* `probe_hourly`:按小时汇总,主键 `(target_id, generation, hour)`。

迁移**不创建任何探测目标**:升级之后面板不会凭空开始连任何机器,由管理员在节点详情里逐台开启。

兼容性:

* 旧节点没填价格与到期 —— 卡片显示「未设置套餐」,估值说明原因,不显示 0;
* 节点 / 外部代理 / 代理源的编辑表单只带到期那几栏,保存时**不带计费字段**,后端按「保持原值」处理
  (`expiry.Params.Billing` 为 nil),不会被表单清空;
* 备份 / 恢复:都在同一个 SQLite 文件里,`litebox backup` 照常;重复跑迁移是幂等的(迁移框架按版本记录);
* 删除节点(软删除)时顺带删除它的探测目标与标签;删除外部代理 / 代理源时删除标签。

## 3. 配置

「系统设置 → TCP 探测」,改了下一轮生效,不用重启:

| 设置项 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `probe_enabled` | 开 | — | 全局开关。关掉后目标与历史保留,不探测、不告警 |
| `probe_interval_sec` | 60 | 15–3600 秒 | 探测间隔 |
| `probe_timeout_ms` | 2000 | 200–10000 毫秒 | 单次 DNS 解析与 TCP 建连各自的超时 |
| `probe_alert_after` | 3 | 0–60 | 连续失败几次推送,0 = 不推送 |
| `probe_quiet_hours` | 不设 | `HH:MM-HH:MM` | 免打扰,可跨午夜,按到期提醒的时区解释 |

推送事件新增两种(可在「监控与推送」里单独关):`PROBE_DOWN`「TCP 探测连续失败」、`PROBE_RECOVERED`「TCP 探测恢复」。

并发上限固定为 8 个同时在飞的连接;不走 SSH、不占节点连接锁,与部署、流量同步、巡检、资源采集互不争抢。

## 4. 指标定义

| 指标 | 定义 |
|---|---|
| TCP RTT | 从主控对目标 `ip:port` 发起连接到三次握手完成的耗时(只对成功的尝试)。DNS 解析耗时单独记,不算进 RTT |
| 一次尝试的结果 | `OK` 成功;`TIMEOUT` 连接超时;`REFUSED` 被拒绝(端口没监听或防火墙拒绝);`UNREACHABLE` 网络不可达;`ERROR` 其他失败;`DNS_ERROR` 域名没解析出来、**没有发起连接**;`SKIPPED` 未执行(云实例停着) |
| TCP 连接失败率 | `失败次数 ÷ 实际发起的 TCP 连接次数`。分母只含 OK / TIMEOUT / REFUSED / UNREACHABLE / ERROR;DNS 失败与未执行不在分母里,单独计数。分母为 0 时是 `null`(界面「—」),不是 0% |
| 连续失败(告警用) | 建连失败与 DNS 失败都算一次;未执行不改变计数 |
| 点阵 | 最近 30 个窗口,每格 `max(2 分钟, 探测间隔)`。OK 全部成功 / PARTIAL 部分失败 / FAIL 全部失败 / DNS 只有 DNS 失败 / SKIP 只有未执行 / NONE 没有样本(空心,**不按正常画**) |
| 数据过期 | 最近一次样本早于 3 个探测间隔 |
| 口径代号 | 目标解析出的地址或端口变了就 `generation + 1`,统计只看当前代号,新旧地址不混在一个失败率里 |

卡片上的失败率、样本数、点阵与历史视图的合计都由同一批窗口相加,分母、样本数与点阵一致
(`internal/probe` 的 `Sum` / `bucketize`,`TestEngineRoundWritesResultsAndStats` 与 `TestHistoryAndPrune` 钉着)。

TCP 能连上只说明端口可连接,**不等于代理协议可用**(那是部署里的真实拨测),也**不是 ICMP 丢包**。
界面上一律写「TCP 延迟 / TCP 连接失败率」。

## 5. 计费与估值规则

* 名称是「**剩余未摊销价值(估算)**」—— 不是余额、不是可退款金额,商家没有承诺按比例退款;
* 按时间:`本期金额 × 剩余有效时长 ÷ 本期总时长`,截断到 `[0, 本期金额]`;本期金额 = 本次实际支付(没填按标价)+ 上期结转;
* 本期起点没填时按到期时间往前推一个周期,**按日历月**(3 月 31 日到期的月付,起点是 2 月最后一天,闰年 29 日);
  自定义按天的周期按天推;一次性与流量包退回购买日期;
* 按流量:`本期金额 × 剩余流量 ÷ 总流量`。节点取本流量周期的计费口径用量,代理源取上游订阅报告的用量,
  外部代理没有流量数据;不限量、总量未知时不估;超额为 0;
* 两种口径**分开列,不相加**;多币种**不换汇、不求和**,成本汇总按币种分行;
* 月均成本 = 周期性套餐的标价折算到每月(按天的周期用平均月长 365.2425 / 12 天);一次性、流量包、永久不进月均;
* 续费只追加历史,同一个 `request_id` 只记一笔账。**提前续费**时上一期没用完的部分按续费那一刻的估值结转进新周期,
  新周期从续费那一刻起算 —— 那段已经付过钱的时间不会在估值里凭空消失;
* 自动续费开关只是登记商家侧的状态,面板不代为扣款、不承诺续费成功;到期未登记新日期仍显示「已到期 · 待确认」;
* 派生量(剩余价值、日均、月均)不入库,读取时现算。

## 6. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/dashboard/cards` | 一次返回全部卡片的计费估值、标签、探测汇总、成本汇总、7 天内到期数。只读库,不连节点、不触发探测 |
| PUT | `/api/asset-labels/{kind}/{id}` | 地区与标签 |
| PUT | `/api/expiry/{kind}/{id}` | 原有接口加可选 `billing`(省略 = 保持原值;金额是十进制字符串) |
| POST | `/api/expiry/{kind}/{id}/renew` | 原有接口加 `amount` / `currency`;新增 `DAYS` 方式;响应加 `period`(新的本期) |
| GET | `/api/expiry/{kind}/{id}` | 原有接口加 `valuation` 与 `labels` |
| GET | `/api/nodes/{id}/probe` | 这台机器的目标汇总 + 可选候选(白名单) |
| POST | `/api/nodes/{id}/probe-targets` | `{ref, family}` 必须是候选之一,否则 400 |
| PUT / DELETE | `/api/probe-targets/{id}` | 暂停 / 恢复 / 改名;删除(连同历史) |
| GET | `/api/probe-targets/{id}/history?range=1h\|24h\|7d` | 窗口、合计、最近失败点 |

全部走原有的管理员会话鉴权。探测目标**不收自由输入的地址与端口**:候选只来自这台机器的管理通道(host + SSH 端口)
与订阅地址条目(`inbound_endpoints`,端口跟随规则与订阅生成一致)。目标存的是引用,每轮重新解析;
机器改了地址目标跟着走(并换代),引用失效(地址 / 入口被删、入口停用、UDP 传输)就停探并标「目标已失效」,
不会继续打一个可能已经属于别人的旧地址。

## 7. 已知限制与没做的事

* **外部代理与代理源不做定时探测**。CLAUDE.md 规定它们的连通性检查只手动触发(定时跑出一堆红灯只会训练人忽略);
  卡片上显示上次手动检查的结果;
* **管理通道的探测会被 sshd 记成未认证连接**(OpenSSH 9.8 起的 PerSourcePenalties,默认每次 1 秒,远低于 15 秒的封禁门槛);
  候选与目标旁边写明了这一点,建议优先监测对外服务端口;
* 一个域名解析出多条记录时只连第一条;
* Mieru 端口段只探测段起点;UDP 传输的 Mieru 入口不能 TCP 探测(列为失效);
* 提前续费的结转在新旧两期单价不同时,中间时刻的估值与逐段摊销略有差异(续费那一刻与到期那一刻两端一致);
* 地区不按名称自动识别,要手工填;
* **P2 未实施**:ICMP 需要额外权限(不能要求整个面板以 root 运行);VPS 出站远端探测要占节点 SSH 与资源,需另行评估;
  电信 / 联通 / 移动三网需要真实测点或可信 API。没有真实测点之前,界面不出现这几行,也不复制主控的数值充数;
* 测试环境的副作用:前端回归里时钟固定(`page.clock.setFixedTime`)时,AntD 的空值下拉框点一下不会展开,
  撤掉固定时钟就正常 —— 用例里改用方向键展开,界面本身没有问题。
